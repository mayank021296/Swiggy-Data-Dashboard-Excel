# Swiggy-Data-Dashboard-Excel

# 🍔 Swiggy Data Analysis & Interactive Excel Dashboard

## 📌 Project Overview

This project is an **interactive Swiggy Data Analysis Dashboard built entirely in Microsoft Excel**.

The dashboard uses Excel's powerful data analysis and visualization features to transform raw Swiggy data into an interactive and easy-to-understand business dashboard.

The project demonstrates how **Excel can be used to perform data analysis and create professional interactive dashboards without using Power BI or other BI tools.**

## 🎯 Project Objectives

* Analyze Swiggy data using Microsoft Excel
* Identify important business trends and patterns
* Analyze restaurant and food category performance
* Create interactive reports using slicers and filters
* Build Pivot Tables and Pivot Charts
* Present insights through a visually appealing dashboard

## 📊 Dashboard Features

The interactive dashboard includes:

* 📌 Key Performance Indicators (KPIs)
* 📈 Interactive charts
* 🍽️ Restaurant analysis
* 📍 Location/City-wise analysis
* 📦 Order-related analysis
* 🏆 Top-performing restaurants/categories
* 🔎 Interactive slicers
* 🎯 Filters for dynamic analysis
* 🖼️ Images and icons for better visualization

Users can interact with the dashboard using **Slicers and Filters** to dynamically explore different segments of the Swiggy data.
